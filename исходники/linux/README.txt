Noxel для Linux x86_64

Распакуйте архив целиком. Для запуска откройте файл noxel.
Для установки в меню приложений запустите ./install.sh из этой папки.
Установка не требует sudo. После установки папку с архивом можно удалить.

Требования: Linux x86_64 с glibc 2.39 или новее, GTK 3, WebKitGTK 4.1, доверенные сертификаты CA.
Ubuntu 24.04 / Debian 13: libwebkit2gtk-4.1-0 libgtk-3-0 ca-certificates.
На других дистрибутивах названия пакетов могут отличаться.
Rust и установленная Java игроку не требуются: Java скачивает Noxel.
Сборка не предназначена для Alpine/musl и Linux ARM.

Данные: ~/.local/share/noxel (либо $XDG_DATA_HOME/noxel).
Журнал запуска: ~/.local/state/noxel/launcher.log.
Horizon: Версии → Rust. Для подготовки нужны файлы Minecraft 26.3
либо вход Microsoft с лицензией для скачивания с Mojang.
Microsoft-вход Horizon требует одобренного Client ID разработчика.
Моды Horizon: Моды → Horizon 26.3. После изменения модов перезапустите игру.

Удаление: ./install.sh --remove из распакованного архива.
Сохранения и аккаунты при удалении приложения остаются.
