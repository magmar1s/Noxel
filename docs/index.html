Noxel

Лаунчер Minecraft. Автор: magmar1s. Открытый код. Лицензия MIT.

Скачать выпуск · Исходный код · Ошибки

Java Edition, Modrinth, Horizon Offline. Установщик позволяет заранее скачать Java, Minecraft и сборку Horizon.

Linux: x86_64, glibc 2.39+, GTK 3, WebKitGTK 4.1. Windows: экспериментальная сборка.

Horizon требует подготовленных файлов Minecraft 26.3. Для лицензионного входа нужен Microsoft-аккаунт и одобренный Client ID приложения.

Аккаунты Noxel, друзья и облачные миры отключены. Данные игрока хранятся на его компьютере.

Разработка: команда проекта Noxel. По сведениям автора, использовались локальные Qwen3.8, GLM5.3 Flash и Claude через API.
