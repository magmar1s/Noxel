Данные Noxel

Автор: magmar1s. Дата: 12 ноября 2026.

Профили, настройки, токены и миры сохраняются на устройстве игрока. Сервер аккаунтов Noxel не используется.

GitHub обслуживает исходный код, каталоги, обновления и изображения скинов. Modrinth, Mojang, Microsoft и Horizon используются для соответствующих загрузок и авторизации. Эти сервисы получают сетевые запросы и могут видеть IP-адрес.

Пароль Microsoft вводится на странице Microsoft. Noxel хранит полученные токены на устройстве. Не передавайте файлы аккаунтов другим людям.

Google Диск используется для резервной копии исходного проекта автора. Данные игроков туда не загружаются.

Удаление локальной папки данных удаляет сохранённые настройки и токены. Сначала сохраните нужные миры.
