# Безопасность

Не публикуй токены и данные аккаунтов в Issues.
Об уязвимости сообщи через GitHub Private vulnerability reporting, если функция
включена, либо опиши проблему без секретов и эксплуатационных данных.
Обновления проверяются по SHA-256 и подписи Ed25519.
Закрытый ключ подписи не входит в исходный код.
