Вход и данные игрока

Эта страница описывает Rust-клиент Horizon Offline, который Noxel запускает внутри своей вкладки «Версии → Rust». Она дополняет общую страницу безопасности Noxel.

Вход Microsoft и лицензия

  • Вход начинается в Noxel, но пароль ты вводишь только на странице Microsoft. Noxel не видит и не сохраняет пароль.
  • Для входа используется Client ID публичного приложения Microsoft. Его можно указать в Noxel: Настройки → Лицензия Microsoft. Это идентификатор приложения, не пароль и не секрет; он остаётся в настройках устройства и не отправляется серверу Noxel.
  • Microsoft, Xbox Live, XSTS и Minecraft Services обмениваются данными, необходимыми для проверки аккаунта, профиля и лицензии Minecraft: Java Edition. Эти запросы идут напрямую из клиента поставщика к соответствующим сервисам.
  • Токены входа хранит Horizon: в системном хранилище учётных данных, если оно доступно, или в зашифрованном файле профиля пользователя. Они остаются на устройстве и не отправляются на сервер Noxel.
  • Локально также сохраняются имя и UUID аккаунта, чтобы показывать выбор профиля. Выйди из аккаунта в Noxel, чтобы удалить его токены с устройства.

Офлайн-профиль

Офлайн-ник хранится только на устройстве и используется для одиночной игры и LAN. На серверы с проверкой Mojang (online-mode) такой профиль войти не сможет. Noxel не заявляет, что офлайн-профиль является лицензией Minecraft.

Телеметрия и сетевые запросы

  • Noxel отключает endpoint телеметрии Horizon при запуске клиента, включая анонимный ping «играю сейчас».
  • Для списка выпусков Noxel получает манифест со своего API; установщик скачивает проверенные SHA-256 файлы с GitHub. Игровые файлы Minecraft скачиваются с серверов Mojang только по отдельному действию и после входа с лицензией.
  • При подключении к игровому серверу этот сервер получает обычные сетевые данные соединения, включая IP-адрес, как при подключении через любой другой клиент. Серверы могут отдельно обрабатывать игровой ник и действия согласно своим правилам.
  • Файлы игры, миры, ник офлайн-профиля и токены не передаются Noxel. При выборе локальной папки Minecraft Noxel использует её для подготовки клиента; исходную установку не изменяет.

Удаление данных

Выйди из Microsoft-аккаунта в Rust-разделе Noxel, чтобы удалить сохранённую авторизацию. Офлайн-ник и игровые файлы можно удалить вместе с папкой данных Noxel: ~/.local/share/noxel/horizon на Linux или %LOCALAPPDATA%\Noxel\horizon на Windows. Перед удалением папки скопируй нужные миры.
