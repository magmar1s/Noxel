# Noxel

Лаунчер Minecraft для Linux и Windows. Автор: magmar1s. Лицензия: MIT.

Исходный код: https://github.com/magmar1s/Noxel
Сборки: https://github.com/magmar1s/Noxel/releases

Возможности:
- Java Edition: Vanilla, Fabric, Quilt, Forge, NeoForge.
- Отдельные папки модов, настроек и миров для профилей.
- Загрузка нужной Java с серверов Mojang.
- Каталог Modrinth и встроенные моды.
- Horizon Offline: Rust-клиент Minecraft 26.3 и каталог совместимых .hmod.
- Локальные аккаунты и Microsoft-вход.
- Импорт скина из PNG, по нику или прямой ссылке GitHub.
- Локальные копии миров и экспорт сборок.
- Установщик с выбором Java, Minecraft и Horizon.
- Подписанные обновления через GitHub Releases.

Сервер Noxel не требуется. Аккаунты Noxel, друзья, туннели и облачные миры отключены.
CurseForge отключён: его API требует отдельный ключ. Для модов используй Modrinth.
Google Диск используется автором для резервной копии проекта, а не для миров игроков.

## Установка

Скачай установщик из Releases. Выбери папку установки, ярлыки и необходимые загрузки.
Horizon скачивается отдельно от файлов Minecraft 26.3. Для их подготовки нужна своя
копия игры либо Microsoft-аккаунт с лицензией. Нативные .hnmod не поддерживаются
каталогом Noxel. Для Microsoft-входа нужен одобренный Client ID приложения.

Linux: x86_64, glibc 2.39+, GTK 3 и WebKitGTK 4.1. Rust и установленная Java игроку
не нужны. Для переносного архива распакуй все файлы и запусти noxel.
Windows-сборки создаются в GitHub Actions; на реальной Windows пока не проверены.

## Скины

Положи PNG в свой публичный репозиторий и скопируй прямую ссылку вида
https://raw.githubusercontent.com/OWNER/REPO/main/skin.png.
В аккаунте Noxel выбери «Скин с GitHub». Для локального аккаунта это локальный скин;
видимость другим игрокам зависит от сервера. Сервер с SkinsRestorer может принимать
такую ссылку через /skin url. Для Microsoft-аккаунта PNG загружается в Minecraft.
Ключи и токены GitHub для публичного PNG не нужны.

## Сборка

Нужны Rust, GTK 3 и WebKitGTK 4.1 с заголовками разработки.

```sh
bash исходники/linux/package.sh
cargo build --release --features custom-protocol --manifest-path установщик/src-tauri/Cargo.toml
```

Результаты лежат в «готовый продукт». Данные установленной Linux-копии:
~/.local/share/noxel. Путь меняется через NOXEL_HOME. Токены и личные данные
не входят в репозиторий и дистрибутив.

## Выпуск

`python3 tools/publish-github.py VERSION` публикует проверенные локальные сборки и подписанный
манифест. Закрытый ключ .keys/release.pem хранится локально. Перед выпуском собери
лаунчер и установщик. Конфигурация каталогов находится в distribution/.
Старые скрипты publish.sh и сервер/ относятся к прежней архитектуре и для новых
выпусков не используются.

## Резервная копия

`bash tools/backup-project.sh` создаёт архив исходников и Git bundle с историей.
Архив можно загрузить в Google Диск. Папки аккаунтов, миров и ключей исключены.
Для восстановления: `git clone Noxel.git.bundle Noxel`.
